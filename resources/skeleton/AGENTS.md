# Desarrollo con GFrame

Para cada tarea de desarrollo, corrección o revisión de esta aplicación, utiliza la skill local `gframe-orchestrator` y los especialistas pertinentes antes de editar. Codex los descubre en `.agents/skills`; Claude Code, en `.claude/skills`. Aplica sus instrucciones y verificaciones, no solo su descripción. No utilices copias globales de otra versión.

Las convenciones se mantienen en las skills del paquete instalado; este archivo no las duplica. No modifiques el core ni el paquete instalado sin petición expresa del propietario. Si hay una etapa activa, respeta su conciliación, tareas y auditoría.
