# Contribuir a GFrame

1. Crea un fork del repositorio.
2. Abre una rama para el cambio.
3. Mantén el núcleo libre de reglas específicas de una aplicación.
4. Añade o actualiza las pruebas correspondientes.
5. Ejecuta `composer check` antes de enviar el pull request.

Los cambios incompatibles deben documentarse y reservarse para una versión principal.
